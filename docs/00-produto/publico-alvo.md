# Público-Alvo — microservice-shop

## Perfil: Desenvolvedor/estudante de sistemas distribuídos

- **Quem é:** Desenvolvedor backend ou engenheiro de dados que quer demonstrar domínio de microsserviços, mensageria e ML/LLM em contexto de negócio
- **Principal objetivo:** Portfólio técnico que mostre múltiplas competências num único projeto
- **Nível técnico:** Intermediário a avançado
- **Frequência de uso:** Demonstração em entrevistas; referência para novos projetos

## O que os usuários NÃO são

- Não são equipes construindo um e-commerce real para produção
- Não são usuários finais comprando produtos
