# Restrições Legais — microservice-shop

## Projeto educacional

Projeto de estudo e portfólio sem dados de usuários reais e sem operação comercial. Não há coleta de dados pessoais nem processamento de pagamentos reais.

## APIs de LLM (experimentos)

Ao integrar APIs de LLM (OpenAI, Anthropic, etc.) nos experimentos:
- Não enviar dados pessoais de usuários reais para APIs externas
- Usar apenas dados de exemplo fictícios nos notebooks
- Verificar os termos de uso da API utilizada — especialmente quanto a treinamento de modelos com os dados enviados
